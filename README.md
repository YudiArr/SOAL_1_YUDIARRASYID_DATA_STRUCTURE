Studi Kasus:
Anda adalah seorang developer pemula di perusahaan teknologi pendidikan (EduTech) yang sedang membangun sistem sederhana untuk mengelola data mahasiswa. Perusahaan ingin sistem tersebut menggunakan prinsip Object-Oriented Programming (OOP) agar mudah dikembangkan di masa depan. Sebagai informasi bahwa setiap mahasiswa memiliki nama, nim, jurusan, dan ipk. Sistem harus dapat menampilkan informasi mahasiswa, menghitung status kelulusan, dan memberikan contoh penerapan konsep enkapsulasi serta method dalam Java.

Soal 1: Pembuatan Class dan Object (Bobot 30%)
Buatlah program Java yang melakukan hal berikut:
1.	Buat kelas Mahasiswa dengan atribut:
•	String nama
•	String nim
•	String jurusan
•	double ipk
2.	Tambahkan constructor untuk menginisialisasi data mahasiswa.
3.	Buat method tampilkanInfo() untuk menampilkan data mahasiswa.
4.	Buat 5 objek mahasiswa dengan data berbeda dan tampilkan seluruh informasinya di konsol.
